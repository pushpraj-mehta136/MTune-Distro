🎵 MTune - High-Fidelity Music Player
Welcome to the official distribution repository for MTune. MTune is a premium, high-performance music player built with Flutter, designed for audiophiles who demand lossless quality and a seamless UI.

🚀 About the Project
MTune is currently distributed as an independent third-party application. This repository serves as the hosting hub for our latest stable releases and automated update metadata.

High-Fidelity Audio: Support for FLAC, WAV, and high-bitrate MP3.

Custom Engine: Optimized background playback and notification controls.

Privacy First: No tracking, no ads, just your music.

📥 How to Install
Since MTune is distributed via APK (sideloading), follow these steps to get started:

Download: Go to the Releases section and download the latest app-release.apk.

Enable Unknown Sources: When you open the file, Android may ask for permission to "Install unknown apps." Toggle this ON for your browser or file manager.

Install: Follow the system prompts to complete the installation.

Enjoy: Open MTune and start your musical journey.
